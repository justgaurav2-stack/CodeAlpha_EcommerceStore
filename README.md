# CodeAlpha E-Commerce Store

A simple full-stack e-commerce web application built with Node.js and Express.

## Features
- Product listing page
- Add to cart and remove from cart
- User registration and login
- Order placement
- Database integration (db.js)

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: (SQLite / MongoDB / MySQL, jo use kiya ho)

## Project Structure
- `public/` : frontend files (HTML, CSS, JS)
- `server.js` : main server file
- `db.js` : database connection
- `package.json` : dependencies

## How to Run
1. Clone the repo:
   git clone https://github.com/justgaurav2-stack/CodeAlpha_EcommerceStore.git
2. Go to the folder:
   cd CodeAlpha_EcommerceStore
3. Install dependencies:
   npm install
4. Start the server:
   node server.js
5. Open http://localhost:3000 in your browser
